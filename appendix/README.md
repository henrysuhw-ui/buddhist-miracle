# 附錄·姑存

存其說，不入正錄。

此處收錄**未達正錄標準**的材料：只見親友轉述者、源頭已失者、真偽難辨者、當事人身份不明者。收在這裡不是背書，也不是判罪，而是「姑存之」——古人編錄，遇可疑者每云「姑存以備考」，我們沿用這個意思。

## 規則

1. 每則須有 `status: pending` 與 `pending_reason`，寫明**為何不入正錄**
2. 四節體例與正錄相同，但「當事人的理解」須改寫為轉述者的理解，並標明
3. 不得因收入附錄而放寬事實描述；寧可寫得比正錄更保守
4. 日後找到當事人本人陳述，可升級入 `cases/`，並在此留一行註記

## 為何不直接丟掉

丟掉，就沒有人知道他會被誤傳；留下來並註明疑點，日後有人再遇到同一則傳聞，至少查得到它已經被查過一次。

## 索引

附錄條目同樣列入 `INDEX.md` 的「附錄」一節，但不計入正錄數目。
