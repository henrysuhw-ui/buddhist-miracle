# 編例 · Editorial Rules

本檔是操作手冊：什麼算合格的一則，怎樣寫，審核時逐項對照。立場與體例的理由見 [README](../README.md)；序另見 [PREFACE.md](../PREFACE.md)。

## 零、只輯公開資料

本錄是**輯錄**，不是採訪，也不是檔案庫。

- 只收已公開發表的影片、音檔、文章、書籍、報刊
- 不收私人提供的經歷、私信、未刊手稿、群組對話
- 編者不主動接觸當事人索取故事；發現公開資料即記，找不到即不記
- 已公開但已刪除者，若有存檔，可據存檔收錄，並在出處行註明「原頁已刪，據存檔」

此條先於一切。資料再感人，只要不是公開的，就不收。

## 一、資格

一則要入正錄，須同時滿足：

| # | 條件 | 說明 |
|---|---|---|
| 1 | 已公開 | 任何人皆可開啟或借閱；不依賴編者手上的私人材料 |
| 2 | 第一手 | 說話者即當事人（自述），或當事人親口所述而他人記錄（口述記） |
| 3 | 可回查 | 有網址或書名＋頁碼，並記存取日期 |
| 4 | 可定位 | 影片有時間戳，文章有段落位置，書有頁碼 |
| 5 | 有存檔 | 網頁須送 Wayback 存檔，網址失效時仍可查 |
| 6 | 一件事 | 一則只記一件事，不併合多人的經歷 |

不合格者不刪，移入 [appendix/](../appendix/) 並註明原因。

## 二、兩級

| 內部代碼 | 顯示 | 定義 | 審核 |
|---|---|---|---|
| `A` | 自述 | 當事人本人以文字／影片／錄音自述，並已公開發表 | 一位編者 |
| `B` | 口述記 | 當事人口述，他人筆錄或拍攝，並已刊行；記錄者身份可查 | 兩位編者 |

`C`、`D`（親友轉述、傳聞）不入正錄，只可入附錄。

### 署名程度 `attribution`

| 值 | 意思 |
|---|---|
| `named` | 真名或穩定筆名，可追溯 |
| `pseudonymous` | 帳號可追溯至同一人的過往發言 |
| `anonymous` | 完全匿名 |

三者皆可為 A 級，但 `anonymous` 須在出處行明示「匿名自述」。不要求實名，亦不假裝匿名等於實名。

## 三、體例

四節，順序固定，標題不可改：

```
## 一句話        一句話說完這件事，不加感嘆
## 情境          年月、地、身份、場合
## 經過          事情本身；引文放這裡
## 當事人的理解   他自己怎樣解釋；一律「他認為」「她相信」
出處：            日期、平台、標題、時間戳／頁碼、存取日期、存檔連結
```

英文條目用 `## In one line` / `## Setting` / `## Account` / `## Their own understanding`，末行 `Source:`。同一則不可中英標題混用。

### 字數

- 中文：正文 120–400 字（不計 frontmatter 與出處行）
- 英文：120–300 words

短於下限，多半是資料不足；長於上限，多半是掺了自己的議論。

### 情境要具體

傳統感應錄靠「年號＋籍貫＋官職」立信，今人靠「年月＋城市＋身份」。寫得乾硬：

- ✓ 二〇二三年十一月，香港，五十餘歲，乳癌第三期，公立醫院
- ✗ 一位可憐的女士，多年來飽受病苦

可識別資料（全名、任職機構、病歷）除當事人同意外，一概不寫。

### 經過與理解要分開

| ✗ | ✓ |
|---|---|
| 觀音菩薩救了她的命 | 她認為是觀音菩薩救了她 |
| 手術後癌細胞消失 | 她說術後病理報告顯示腫瘤較預期小 |
| 念佛之後就考上了 | 她說考前一直念佛，後來放榜錄取 |

編者不在場，不可代當事人斷言因果。這條是硬規則。

### 引文

- 每則最多兩條，單條不超過八十字
- 必須逐字，不可改寫、不可拼接
- 必附時間戳或頁碼
- 標點依原文；方言照錄

### 出處行

一行寫完，末句自陳所未見：

```
出處：二〇二四年三月二日，YouTube「某某頻道」〈標題〉，12:34。
https://youtu.be/xxxx?t=754 ｜ 存檔：https://web.archive.org/web/xxxx
編者未親見，未見病歷。
```

無病歷可提者，寫「編者未親見，僅據其自述」。

## 四、禁用語

以下詞句代當事人斷言，一律改寫。校驗腳本會攔截部分，其餘靠審核。

`菩薩救了他`、`佛菩薩顯靈`、`奇蹟般`、`神奇地`、`不可思議地痊癒`、`證明瞭`、`科學無法解釋`、`親身見證奇蹟`

「無法證明」「不能據此斷定」一類否定句不禁。

## 五、主題

沿用歷代分類，小幅現代化。frontmatter `theme` 可多值。

| 歷代 | 本錄 |
|---|---|
| 疾病 | 疾病 |
| 水火盜賊 | 意外危難 |
| 功名（科舉） | 考試、升學、求職 |
| 嗣息 | 求子 |
| 冥報、冤親 | 現世報應、超度 |
| 往生、臨終瑞相 | 臨終、喪葬 |
| — | 成癮與改過、精神健康、移民簽證 |
| — | 夢兆、失物尋人、動物 |

新增主題請先開 issue 討論，避免同義詞分裂。

## 六、審核清單

- [ ] 資料為公開來源，不依賴任何私人材料
- [ ] 說話者確為當事人（或經授權之記錄者）
- [ ] B 級已確認該記錄曾公開發表
- [ ] 連結可開，時間戳正確對應引文
- [ ] 已送 Wayback 存檔，`archived` 已填
- [ ] `retrieved` 為實際存取日期
- [ ] 四節齊備，字數合規
- [ ] 「當事人的理解」全用「他認為／她相信」
- [ ] 無禁用語
- [ ] 無未經同意之可識別資料
- [ ] 出處行末有「編者未親見」
- [ ] 級別與署名程度填寫正確
- [ ] `npm run validate` 通過
