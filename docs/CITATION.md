# 引用格式 · Citation

本錄無固定網址，故引用時請用**帶 commit 的連結**，以免日後內容修訂而使引文失準。

## 中文

> 編者。〈標題〉。《現代佛教感應錄》（buddhist-miracle），條目 #0007。
> https://github.com/OWNER/buddhist-miracle/blob/COMMIT_SHA/cases/2024-hk-0007-surgery-dream.md
> 存取日期：2026-10-22。

## English

> *A Record of Modern Buddhist Responses* (buddhist-miracle), entry #0007, "Title".
> https://github.com/OWNER/buddhist-miracle/blob/COMMIT_SHA/cases/2024-hk-0007-surgery-dream.md
> Accessed 2026-10-22.

## 取得 commit 連結

1. 開啟該條目檔案
2. 按 `y`，網址即變為當前 commit 的固定版本
3. 複製該網址

## 注意

- 引用摘要時，請一併引用其原始出處（條目末行），不要只引本錄
- 本錄之摘要為編者所寫，非當事人原文；引述當事人的話，請回到原始連結
- 條目可能因當事人要求而移除；若連結失效，流水號不會重用，可用 `#0007` 檢索

## 批次取用

`INDEX.md` 與 `exports/cases.json` 由 `npm run index` 生成，供研究者取用。資料欄位定義見 [EDITORIAL.md](EDITORIAL.md)。
