## 收錄

1. **當事人本人自述**——影片、錄音、文章、書中第一人稱記述，且已公開。
2. **已公開發表的口述記錄**——當事人口述，他人記錄並刊行（訪談、紀錄片、播客、報刊）。
3. **附出處**——網址與時間戳，或書名與頁碼；記下存取日期，網頁另存快照。
4. **只寫摘要**——一則一百至四百字，不轉載全文、不重上載影片，引文短而附時間戳。
5. **不收**——聽來的、轉述再轉述、私人提供的經歷、未刊手稿、群組截圖。即使出於善意。

編者只做輯錄，不做採訪，亦不代人披露私事。

## 體例

檔名：`cases/YYYY-地區-流水號-slug.md`（例 `2024-hk-0001-surgery-dream.md`），流水號四位，不重用。

每則如此：

```markdown
---
id: "0001"
date: 2023-11
place: 香港
theme: [疾病, 夢兆]
tag: 自述
---

# 手術前一夜，她夢見白衣人

## 情境
二〇二三年十一月，香港。陳女士（化名），五十多歲，中學教師，乳癌第三期，住在公立醫院等手術。

## 經過
她說，手術前一晚，她念佛念到睡着。夢裏有一個白衣人站在床邊，沒有說話，也沒有光。
她醒來時天還沒亮，心裏很安定，手也不再抖。第二天早上進了手術室。手術後的病理報告顯示，
腫瘤比手術前評估的小。「我當時只係一路念，念到唔知幾時睡着。」

## 當事人的理解
她認為那是觀音菩薩示現，令她不再恐懼；至於腫瘤較小，她說不敢斷定與夢有關。

出處：二〇二四年三月二日，YouTube「某某頻道」〈手術前的一夜〉，12:34。
https://youtu.be/xxxx?t=754 ｜ 存檔：https://web.archive.org/web/xxxx
```

> 上例為虛構示範，非真實案例。

幾條要緊的：

- **標題就是一句話**。寫事實，不設懸念：〈手術前一夜，她夢見白衣人〉，不是〈觀音顯靈！癌細胞奇蹟消失〉。
- **標題寫人，不寫地**。以當事人起題（歷代感應錄即如此），地名留在「情境」。
- **白話直敘**。一句一事，主語要出現；不寫「置於」「不輟」「復見」一類文言詞，行話只可出現在引文裏。
- **情境要具體**。年月、城市、身份、場合，寫得乾硬。可識別資料（全名、病歷、任職機構）除當事人已在公開資料中披露，一律不寫，可用化名。
- **經過與理解分開**。第三節只記事情，第四節只記當事人自己怎樣解釋。
- **一律「他認為」「她相信」**，不代當事人斷言因果。編者不在場。

標記只有兩種：**自述**（當事人本人所述）、**口述記**（當事人口述，他人記錄並刊行）。
