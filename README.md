# 現代佛教感應錄 · buddhist-miracle

輯錄現代人的佛教感應記事。一則一檔，每則附原始出處。

**本錄只輯已公開發表、可回查的資料，不收取私人故事。**

**本錄所重者，出處可尋；不宣稱感應已得證實。**

感應之為感應，本來就是當事人的親身經歷。我們能做、也只做一件事：把他親口所說、親筆所寫的，連同可以回查的連結與時間戳，一併留下來。信者恆信，不信者姑妄聽之。

## 這是一份什麼樣的錄

歷代感應錄所記，多是千百年前的事。年代既遠，人物、官職、地名皆已難考，今人讀之，往往隔了一層。本錄取現代人：有聲音、有影像、有帳號、有網址，可以自己點進去看他怎樣說。

一則不長，一百至四百字。我們只寫摘要，因為摘要讀得快，也因為全文的權利屬於當事人。想細看，請循出處回看原件——那才是這份錄真正想讓你讀的東西。

## 收錄原則

1. **當事人本人自述**——影片、錄音、文章、書中第一人稱記述。
2. **已公開發表的口述記錄**——當事人口述，他人筆錄或拍攝，並已刊行（訪談、紀錄片、播客、報刊）。
3. **附出處**——網址或書名頁碼，並記錄存取日期；網頁另存快照。
4. **只寫摘要**——不轉載全文、不重上載影片，引文短而必附時間戳或頁碼。
5. **不收**——聽來的、轉述再轉述、無源可溯者。此類另置 [附錄·姑存](appendix/)，存其說而不入正錄。

親友轉述、法師講述信眾故事、長輩口中的「某人說」，一概不取。私人提供的、未公開發表的故事，亦不收取——即使出於善意。編者只做輯錄，不做採訪，亦不代人披露私事。寧可少，不願以訛傳訛。

## 怎樣讀：兩種標記

| 標記 | 意思 |
|---|---|
| **自述** | 當事人本人所述 |
| **口述記** | 當事人口述，他人筆錄或拍攝，已公開發表 |

標記只說「來源離當事人多遠」，不說事件真假。真假一事，錄中不作判斷，亦不能作判斷。

## 一則的體例

```
## 一句話
## 情境        ← 年月、地、身份、場合，寫得乾硬具體
## 經過
## 當事人的理解   ← 一律「他認為」「她相信」，不代當事人斷言
出處：日期、平台、標題、時間戳或頁碼、存取日期。編者未親見，所缺者附記。
```

第三節「經過」記事情本身，第四節「當事人的理解」記他自己怎樣解釋這件事。二者分開，是因為我們只聽得見他的話，看不見他的因果。

末行「編者未親見」一句，就是本錄全部的方法。它放在該放的位置：不擺在前面教訓讀者，也不藏起來假裝周全。

## 投稿

見 [CONTRIBUTING.md](CONTRIBUTING.md)。最簡便的方式是開一個 [投稿 issue](../../issues/new?template=submit-case.yml)，貼上**已公開的原始連結**與你看到的時間點，其餘由編者整理。請勿提供未公開的私人經歷。

## 下架

**當事人要求下架，七日內無條件移除，不需理由。** 來信或開 issue 均可。此事不作討論，不記錄異議。
